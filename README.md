#  IA Consciente

### Uso Consciente e Seguro da Inteligência Artificial

Projeto desenvolvido como parte de uma atividade extensionista do curso de Engenharia de Software.

O objetivo é apresentar de forma simples e interativa como a Inteligência Artificial funciona, seus benefícios, seus riscos e os cuidados necessários para utilizá-la de maneira consciente e segura.

##  Acesse o projeto

👉 https://daraprisantos.github.io/ia-consciente/

##  Conteúdos abordados

- O que é Inteligência Artificial
- Como a IA funciona
- Exemplos de IA no cotidiano
- Benefícios da Inteligência Artificial
- Riscos e informações falsas
- Cuidados com dados pessoais
- Uso consciente e responsável da IA

## Recursos do projeto

O site possui um quiz interativo com perguntas sobre o conteúdo apresentado.

Também possui um desafio **“Real ou criada por IA?”**, no qual o participante compara uma fotografia real com uma imagem criada por Inteligência Artificial.

##  Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

##  Objetivo

Contribuir para o letramento digital e incentivar o uso consciente, crítico e seguro da Inteligência Artificial.
